# Status da Meia Lua

A página de status de [meialua.app.br](https://meialua.app.br), em **status.meialua.app.br**. Fica fora do servidor da mesa
(GitHub Pages) para continuar no ar quando ele cai.

- **Agora:** pergunta ao `/saude` da mesa a cada minuto.
- **Os últimos 30 dias e as quedas:** vêm do UptimeRobot, com uma chave **só de leitura, de um monitor** (`CHAVE` no `index.html`).
  Sem a chave, a página mostra só o agora.
